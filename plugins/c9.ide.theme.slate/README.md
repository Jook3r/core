# Slate skins

Slate Dark and Slate Light are skins for Cloud9, with an editor theme each.
Slate Dark is the skin of a new installation; choose another in
Preferences > Themes, or in View > Themes.

What they look like:

- **Cards on a window.** The side panel, each editor pane and the console
  are cards with round corners, a step lighter (dark) or white (light) on a
  window of one cool grey. Floating things (menus, dialogs, completion) are
  one step further. There are few lines: a step of grey tells two areas
  apart.
- **Tabs are pills** inside their card: the active one is filled, the others
  show on hover.
- **Icons are drawings, not a font or bitmaps**: SVG masks painted in the
  colours of the palette, sharp at any zoom. The interface's are
  [Lucide](https://lucide.dev)'s; a file has the mark of its language or
  tool (from [Simple Icons](https://simpleicons.org)) in the file tree, in
  its tab and in Navigate, for some 180 extensions and file names.
- **One palette** for the interface, the editor themes (Slate Dark, Slate
  Light), the terminal's 16 colours and the file icons.

## Preferences

Preferences > User Settings > User Interface:

- **Slate Theme: Accent Colour**: Blue, Violet, Teal, Green, Amber or Rose,
  for the primary button, switches, links, matches and the focus ring.
- **Slate Theme: Follow the System's Dark Mode**: the skin changes between
  Slate Dark and Slate Light with the system (or the browser), also while
  the IDE is open, with the editor theme and the terminal colours of the
  variant. Off by default.
- **Slate Theme: Interface Text Size**: 11 to 16px (13 by default), for
  the text of trees, tabs, menus and dialogs. Rows keep their height.

They apply while a Slate skin is active.

## How it is built

| | |
|-|-|
| `plugin.js` | registers the skins and editor themes, the preferences, and writes the accent and text size to `<html>` as custom properties |
| `less/palette-dark.less`, `palette-light.less` | every colour, under the same names in both |
| `less/palette.less` | Cloud9's base theme variables mapped to those colours |
| `less/tokens.less` | radii, spacing, sizes, shadows, type |
| `less/icons.less` | the icons; generated by `tools/gen-icons.js` |
| `less/parts/*.less` | the rules, one file per area |
| `ace.themes/` | the editor themes; the CSS is generated by `tools/gen-themes.js` |

`plugins/c9.static/build.js` lists these files for the two skins
(`slateLibs`); `scripts/install-sdk.sh` builds them into the packed client
with the others.

The accent is two custom properties, `--sl-accent` (fills) and
`--sl-accent-text` (text and lines), with Blue as the fallback in the
palettes. A token that is a custom property can't go through a LESS colour
function (`fade`, `darken`): the build fails on one. Use `color-mix()`.

To change an icon or add a file type, edit the tables in
`tools/gen-icons.js` and run it (its first lines say how). The class of a
file's icon is its extension, or its name when it has none (`Dockerfile`,
`Makefile`); `package.json` is `npm`. That is decided by `getIconClass` in
`plugins/c9.ide.theme.jett/plugin.js`, which also puts the icons in the
tree, the tabs and Navigate for this skin.

Other plugins have a few colours per skin in tables of their own (the
terminal, the output, previews, the diff editors): search for `slate-dark`.
